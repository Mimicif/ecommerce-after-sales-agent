# M2 验收合同（开发前定义）

范围：确定性 API、客户确认、人工审核、仓库、持久化退款 worker、本地模拟支付、人工工单。没有模型调用或真实支付。

完成条件：
- 普通退货：草稿→客户摘要/确认→提交→审核→仓库收货→模拟退款并只记账一次。
- 损坏：证据归属核验，独立人工审核，可明确无需退回；缺政策/未签收/部分退款等转人工工单。
- 客户、客服、审核、仓库与跨租户隔离；员工不能批准自己创建的申请。
- 摘要绑定订单版本/政策摘要/金额/申请版本，15分钟边界、编辑失效、事务消费确认。
- 幂等记录、活动申请部分唯一索引、订单锁、版本比较、审计，重复和并发可验证。
- 退款任务重启后可领取；租约与令牌阻止旧 worker 回写；超时先查询同一操作键；三次失败转人工。
- 模拟支付已成功但本地崩溃，恢复查询原结果；两个 worker /重复恢复累计成功退款只增加一次。
- 真实 PostgreSQL 全套回归、迁移与真实 HTTP 演示，保存实际证据后再标记完成。

最小实施选择见 ADR-015。验收结果完成后追加，不能提前写 PASS。
