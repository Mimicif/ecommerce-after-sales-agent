## 结果口径与限制

所有金额/状态以真实PostgreSQL和后端结果评分，不用LLM判资金。模型事实指标为结构化最终断言及可解析失败尝试，辅以有边界的金额/日历日期/状态检查；状态卡由后端生成。不是全部自然语言语义的准确率，引用存在也不证明整段语言都由条款支持。场景可有多种合法工具路径。

B0固定表单拥有相同授权API，响应通常更快；B1只读子集与B2相同模型，但没有写工具，不能比较写任务的失败。小样本和三次相关重复的Wilson区间只作描述，不是生产可靠性估计。延迟是活跃任务，含模型/工具/生成确认卡，不含初始化schema和人工等待；ASGI合同评测之外另有真实HTTP冒烟。

token、估算价格区间来自已落库usage，失败调用可能在usage落库前仍被计费，不是精确账单。模型别名可能更新；2026-10-12核验价格来源为[DeepSeek官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)。全部仅本地模拟数据、开发身份及模拟支付，没有前端/生产鉴权/真实支付或部署。M5尚未开始。
